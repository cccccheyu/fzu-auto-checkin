4没有 GitHub 账号？手动配置

📌 生成配置后，下面有完整的一步步引导，照着做就行。

🌐 关于梯子：GitHub 国内直连时好时坏，只有注册和配置那几分钟可能打不开——换个时间、用校园网 / 手机热点，或挂梯子都行。配好之后就不用了：签到跑在 GitHub 服务器上，日常零操作、零网络要求。

  1. 没有 GitHub 账号？点这里免费注册，1 分钟搞定（需要邮箱）。
  2. 点这里把项目导入到你自己的私有仓库：① "Your old repository's clone URL" 填 https://github.com/cccccheyu/fzu-auto-checkin；② 仓库名随意；③ 选择 Private（私有，重要！你的密码只有你自己能看到）；④ 点 Begin import。
  3. 导入完成后，在你的仓库页面依次打开：Settings → Secrets and variables → Actions → New repository secret，Name 填 CONFIG_YAML，Secret 粘贴上面复制的内容，点 Add secret。
  4. 完成！之后每晚 21:35 / 21:50 自动签到，可在仓库的 Actions 标签页查看签到记录。签到结果可回第 3 步配置微信推送。

操作详情见仓库 README。
